Agent Autoloop New

Self-hosted MIT hub that hands cron jobs, GitHub issues and error reports to Claude Code, Codex or any CLI agent in the background, and only pings you on Feishu, Slack, DingTalk or desktop when a risky step needs your call; the agent exits while waiting, so no tokens burn
