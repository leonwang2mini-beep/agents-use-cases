sandbox-mcp New

MIT CLI (sbx) plus optional MCP server by Scott Hanselman that boots a fresh, network-off Windows Sandbox, deploys your app, drives it with UI Automation, keeps screenshots and crash evidence, then deletes the machine — catches "works on my machine" bugs in ~40-50 s (needs Windows Pro/Enterprise/Education)

Pricing: Free · Official site · Added 2026-11-11
